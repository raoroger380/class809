## 🌐 网站概览

这是一个为 **澜石中学2023届9班** 定制的班级官方网站，用于集中存储和展示班级活动照片、视频、通讯录等珍贵回忆。网站通过口令访问，保护班级隐私。

### 主要功能

| 功能 | 说明 |
|------|------|
| 🔒 **口令访问** | SHA-256 加密验证，保护网站内容仅限班级成员访问 |
| 🏠 **首页** | 班级概览、数据统计、功能引导 |
| 📸 **精彩瞬间** | 按类别筛选的相册集（班级活动、运动会、春游、节日庆典） |
| 🎥 **视频播放** | 内置视频播放器，支持在页面内直接播放班级视频 |
| ☁️ **网盘下载** | 提供 Google Drive、百度网盘、123云盘多个渠道下载完整相册 |
| 📞 **通讯录** | 班级同学联系方式查询，支持按姓名/学号/电话搜索 |

### 相册分类

## 🚀 本地运行

由于是纯静态网站，任何 HTTP 服务器均可托管：

```bash
# 使用 Python 内置服务器
python -m http.server 8080

# 或使用 Node.js http-server
npx http-server .
```

打开浏览器访问 `http://localhost:8080` 即可。

> ⚠️ **注意**：因为使用了 ES2020 的 `crypto.subtle.digest`（用于口令验证），部分功能需要 HTTPS 或 `localhost` 环境才能正常工作。

## 🔐 访问口令

网站通过口令验证保护，使用 SHA-256 哈希校验，**不存储明文密码**。

- 默认口令哈希存储在 `index.html` 中的 `PASSWORD_HASH` 常量
- 可以使用 `encrypt_809520.py` 生成新口令的哈希值
- 验证通过后使用 `sessionStorage` 保持登录状态（关闭标签页后失效）
